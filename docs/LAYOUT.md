# Layout clássico

A versão 0.2.0 segue a organização das telas oficiais do GasExpert: menus superiores, ícones com legendas, barras de ferramentas, janelas internas com título azul, campos compactos, controles cinza e grades com fundo escuro nas áreas vazias.

As imagens públicas são de versões clássicas 2014/2016. O papel de parede local de 2020 foi inspecionado para referência da paleta azul. A aparência específica da instalação local de 2020 não foi confirmada executando o programa; não se trata de uma reprodução pixel a pixel.

A nova interface usa código próprio e ícones Lucide; não incorpora imagens, marca, skins, executáveis ou código descompilado do original. Só apresenta ações que o projeto implementa. Não adiciona campos ou integrações sem persistência apenas para imitar uma tela.

Na consulta: branco indica pedido ainda sem recebimento; amarelo indica recebimento em forma à vista; verde indica pedido a prazo; vermelho indica cancelamento. Os filtros de pagamento consultam a forma registrada, enquanto a coluna Situação informa o estado real e o saldo pendente.
